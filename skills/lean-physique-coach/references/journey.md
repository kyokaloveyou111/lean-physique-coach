# 这条路会遇到什么

阶段按能力、记录和恢复划分，不按“第几天一定有腹肌”。前两周默认重建习惯，其他阶段因人而异。

| 阶段 | 可能遇到 | 最小行动 | 进展依据 |
|---|---|---|---|
| 建立基线 | 体脂未知、吃多少不清楚、镜子和秤不一致 | 记录典型生活、同条件体重、腰围和真实训练 | 条件与未知项清楚 |
| 恢复习惯 | 动作生疏、酸痛、想猛练、器械排队 | 热身＋主要动作，记录余力和不适 | 三次力量融入日程，恢复不影响日常 |
| 持续进步 | 次数先涨、腰围降但体重不变、外形变慢 | 比同动作记录，按双重进步法调整 | 至少两周可比记录支持目标 |
| 处理平台 | 力量卡住、睡眠差、外食漏记 | 查执行和恢复，一次改一个变量 | 有足够数据判断调整效果 |
| 长期维持 | 动力下降、旅行、忙、体重回升 | 保留每周 2–3 次可持续力量与正常饮食 | 生活变化后能恢复习惯 |

## 常见情况与下一步

**酸痛／疼痛：** 延迟肌肉酸痛不证明训练更有效。轻酸痛可减量或换活动；尖锐、关节定位明确、加重的痛或肿胀不稳，停诱发动作。模型不诊断。

**体重隔天上涨：** 盐、碳水、水分、肠道内容物或称重条件都可能影响。一个数不能判原因或脂肪变化；收集周均、腰围和至少两周趋势，不猛减餐。

**力量不涨：** 前期力量提高也包含熟练和神经适应，不是加重必然对应肌肉增长。查动作幅度、休息、RIR、恢复；同重量多一次也是进步，两三次可比训练没进步再排查。

**外食／奶茶：** 如实记录，下一餐正常安排，不赋予失败标签。若常因太饿过量，检查限制是否太强和餐次是否合适。

**漏练／出差：** 接未完成 A/B/C 顺序，或做简化版，不把三天塞一天。无器械时用适合俯卧撑变式、已有弹力带和耐受下肢动作；没拉的器械承认缺项，不用不牢固门桌或危险背包负重。

**球赛与力量冲突：** 高强度球赛或游泳也是负荷，替代第四次力量；考虑下一次疲劳，不把爱好全变任务。

**膝盖不适：** 停加重及诱发项目，问具体动作和运动后反馈，换已耐受活动；反复症状建议评估。不凭体重或手术时间归因，不用轻负荷保证安全。

**外形焦虑：** 不用 10%／13%／15%给颜值分级。肌肉、脂肪分布、姿势、光线与差异影响外形；降低体脂不是无限收益。一起看腰围、表现、精力和满意程度。

**已经满意：** 维持相近训练刺激和饮食，不再强制每周加重／降体脂。持续不适或疲劳优先恢复。

## 每周复盘

1. 列实报：计划与完成次数、简化次数、体重样本与均值、腰围、可比动作、睡眠和不适。
2. 比本周／前周；无前周则本周是基线。少于三次体重只有有限观察。照片可选并本地保存。
3. 区分事实、推断与不能判断，不自诊。
4. 选继续／维持／减量／一个饮食或活动调整，给理由和下周观察指标。
5. 留一个最小行动，不补练或惩罚性减餐。
